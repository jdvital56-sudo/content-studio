# Ключи и заявки на площадки (шаг 0.5)

Всё делает владелец в браузере. Пароли и ключи он нигде не пишет в чат. Claude проверяет результат.

## 1. Свой ключ Google для Диска (rclone). Срочно, ~15 мин

Зачем: общий ключ rclone, по словам самого rclone, **перестанет работать в 2026 году**. После этого архив на Диск остановится.

1. Открой console.cloud.google.com под своим Google.
2. Сверху «Выбрать проект» → «Новый проект». Название `content-studio`. В этом же проекте потом будет и YouTube.
3. В поиске сверху набери **Google Drive API** → «Включить».
4. Слева «Google Auth Platform» (или «OAuth consent screen») → «Начать». Название приложения `content-studio`, почта своя. Аудитория: **External (Внешняя)**. Контакты свои → согласиться → «Создать».
5. Слева «Data Access» → «Add or remove scopes». Внизу в поле «Manually add scopes» вставь одну строку:
   `https://www.googleapis.com/auth/drive.file`
   → «Add to table» → «Update» → **«Save»** внизу.
   Это доступ только к файлам, которые создал сам завод. Остальной Диск завод не видит.
6. Слева «Audience» → «+ Add users» → твоя почта → «Save».
7. Слева «Overview» (или «Clients») → «Create OAuth client» → тип **Desktop app** → «Create».
8. Появятся **Client ID** и **Client secret**. Окно не закрывай.
9. «Audience» → **«PUBLISH APP»** → подтвердить. Без этого вход слетает каждые 7 дней.
   Если кнопка серая, Google просит адрес сайта и политики приватности. Напиши Claude «кнопка серая», он сделает простую страницу.
10. Напиши Claude «ключ готов». Он откроет тебе окно, ты вставишь туда Client ID и secret (не в чат), браузер спросит разрешение, и Claude проверит Диск.

## 2. YouTube API. Подать сейчас, проверка идёт неделями

1. В том же проекте: в поиске **YouTube Data API v3** → «Включить».
2. В «Data Access» добавь строку `https://www.googleapis.com/auth/youtube.upload`.
3. **Важно:** пока проект не прошёл проверку Google (аудит), загруженные через API ролики становятся **только приватными**.
4. **Поправка 17.11:** форму аудита («YouTube API Services Audit and Quota Extension Form») подаём, когда стена уже работает (конец этапа 1). Проверяющие спрашивают, как устроено приложение, а заявку без готового приложения скорее отклонят. Текст и снимки экрана готовит Claude.
5. До одобрения завод готовит пакет, а публикуешь ты руками.

## 3. TikTok. Подать, когда понадобится этап 5

developers.tiktok.com → свой аккаунт разработчика → приложение → продукт **Content Posting API**. До проверки TikTok ролики через API тоже идут только приватными. Текст заявки готовит Claude.

## 4. Instagram и Facebook (Meta)

developers.facebook.com → приложение типа «Business». Нужен профессиональный аккаунт Instagram, связанный со страницей Facebook. Пока приложение в режиме разработки, оно работает с аккаунтами, где ты админ, и проверка Meta для своих аккаунтов, по документации, не нужна. Это проверим на деле, когда дойдём до этапа 5.

## Порядок

Сейчас: **пункт 1** (Диск) и включить YouTube Data API. Аудит YouTube в конце этапа 1. TikTok и Meta перед этапом 5: им нужен адрес сайта, политика приватности и видео, где показано, как приложение работает, а это появится только вместе со стеной.
