# Content Studio

Наш собственный контент-завод. Одна стена в браузере (и на телефоне) показывает все ролики всех каналов. Ночью завод пишет сценарии, собирает ролики нашими движками, проверяет качество и готовит ролик с подписью к публикации. Без кнопки владельца «Одобрить» ничего не выходит.
