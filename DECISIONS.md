# Решения

Приняты владельцем на разборе 17.11.2026. Новые внизу. Решённое не переспрашивать.

## Продукт

- **Строим своё.** Платные сервисы монтажа и публикации (makerzz, Post for Me) не покупаем. makerzz только список идей.
- **Для кого:** сначала свои каналы, потом клиентам или как сервис. Строим под свои, о продаже пока не думаем.
- **Каналы:** на стене видны все. В первый месяц активны **Kosta Method, What if (стикмены), Исторический (Османы)** и говорящая голова владельца после шага 3.
- **Ролики:** на старте из наших генераторов (без лица). **Нарезка говорящей головы обязательна**, вторым шагом: владелец и другие люди (Тетяна, клиенты), язык определяется сам.
- **Объём:** 1–2 ролика в день на активный канал.
- **Уникализатор** = только A/B-версии одного ролика (другой хук, нарезка, музыка, субтитры). Не обход проверки дублей и не ферма аккаунтов.

## Площадки и публикация

- **Первый месяц:** Instagram Reels, YouTube Shorts, TikTok. Завод готовит ролик и подпись, **публикует владелец в один клик**.
- Параллельно подаём заявки на API YouTube, TikTok и Meta для автопубликации.
- Потом по одной: Facebook, LinkedIn, X, Threads, Pinterest, Telegram.
- **Комментарий → директ:** позже, для **всех** аккаунтов.
- **Цифры в первый месяц:** владелец раз в неделю присылает скрины статистики, завод их разбирает. Потом через API.

## ИИ и агенты

- **Сценарии:** Claude Code по подписке владельца (`claude -p`), ночью, пачкой. **DeepSeek не подключаем.**
- Позже владелец заведёт **отдельный аккаунт Claude только для завода**: завод читает один токен из своих настроек, смена = замена токена. Для роликов клиентам за деньги нужен ключ API (условия Anthropic проверить перед продажей).
- **Главный агент: Продюсер.** План на неделю, раздаёт задачи, будит владельца только для решений. Публикация и траты только через кнопку владельца.
- **Агенты на старте (4):** Сценарист, Критик, Упаковщик, Продюсер. Потом: Факт-чекер, Трендвотчер, Аналитик, Сторож прав, Комьюнити.
- Агент = вызов Claude с нужным скиллом, а не программа, работающая весь день.

## Где работает

- **Сначала ПК владельца.** Сервер €5–10 в месяц, когда завод начнёт приносить деньги.
- **Интерфейс:** стена в браузере + Telegram-бот.
- **Вид:** тёмная студия, пишем с нуля по скриншотам макета (кода макета нет).
