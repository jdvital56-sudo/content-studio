# Решения

Приняты владельцем на разборе 17.11.2026. Новые внизу. Решённое не переспрашивать.

## Продукт

- **Строим своё.** Платные сервисы монтажа и публикации (makerzz, Post for Me) не покупаем. makerzz только список идей.
- **Для кого:** сначала свои каналы, потом клиентам или как сервис. Строим под свои, о продаже пока не думаем.
- **Каналы:** на стене видны все. В первый месяц активны **Kosta Method, What if (стикмены), Исторический (Османы)** и говорящая голова владельца после шага 3.
- **Ролики:** на старте из наших генераторов (без лица). **Нарезка говорящей головы обязательна**, вторым шагом: владелец и другие люди (Тетяна, клиенты), язык определяется сам.
- **Объём:** 1–2 ролика в день на активный канал.
- **Уникализатор** = только A/B-версии одного ролика (другой хук, нарезка, музыка, субтитры). Не обход проверки дублей и не ферма аккаунтов.

## Площадки и публикация

- **Первый месяц:** Instagram Reels, YouTube Shorts, TikTok. Завод готовит ролик и подпись, **публикует владелец в один клик**.
- Параллельно подаём заявки на API YouTube, TikTok и Meta для автопубликации.
- Потом по одной: Facebook, LinkedIn, X, Threads, Pinterest, Telegram.
- **Комментарий → директ:** позже, для **всех** аккаунтов.
- **Цифры в первый месяц:** владелец раз в неделю присылает скрины статистики, завод их разбирает. Потом через API.

## ИИ и агенты

- **Сценарии:** Claude Code по подписке владельца (`claude -p`), ночью, пачкой. **DeepSeek не подключаем.**
- Позже владелец заведёт **отдельный аккаунт Claude только для завода**: завод читает один токен из своих настроек, смена = замена токена. Для роликов клиентам за деньги нужен ключ API (условия Anthropic проверить перед продажей).
- **Главный агент: Продюсер.** План на неделю, раздаёт задачи, будит владельца только для решений. Публикация и траты только через кнопку владельца.
- **Агенты на старте (4):** Сценарист, Критик, Упаковщик, Продюсер. Потом: Факт-чекер, Трендвотчер, Аналитик, Сторож прав, Комьюнити.
- Агент = вызов Claude с нужным скиллом, а не программа, работающая весь день.

## Где работает

- **Сначала ПК владельца.** Сервер €5–10 в месяц, когда завод начнёт приносить деньги.
- **Интерфейс:** стена в браузере + Telegram-бот.
- **Вид:** тёмная студия, пишем с нуля по скриншотам макета (кода макета нет).

## Хранилище (17.11)

- Рабочая папка: `C:\src\content-studio` (кириллица в пути ломает инструменты).
- Первый бесплатный шаг: разобрать `projects` (одна yt-factory весит 53 ГБ). Claude составляет список, удаляет владелец.
- ~~Архив готовых роликов: Backblaze B2.~~ Заменено 17.11, см. ниже.
- **Архив готовых роликов: Google Drive владельца** (Google One, свободно 300 ГБ, доплат нет). Папка `content-studio` на Диске, загрузка через rclone. Завод занимает **не больше 200 ГБ**: остальное место общее с Gmail и Фото, при полном Диске почта перестаёт приходить. Готовый рилс ≈ 50 МБ, ≈ 9 ГБ в месяц, лимита хватит примерно на 2 года. Исходники удаляются через 30 дней после публикации. B2 остаётся запасным вариантом.
- **Автоудаление с Диска (17.11):** готовые ролики удаляются через **60 дней** после публикации. **Навсегда остаются:** хиты (лучшие по просмотрам на канале) и тексты всех роликов (сценарий, хук, подпись). **За 3 дня** до удаления завод присылает список, владелец может что-то спасти. На Диске постоянно ≈ 18 ГБ.
- Доступ rclone к Диску: **только к файлам, которые создал сам завод** (scope `drive.file`), остальные файлы владельца ему не видны.

## Продажа завода: всё своё у каждого клиента (18.11)

Владелец: при продаже каждый покупатель подключает своё, а не движок владельца. Решение: так и строим.

- **Google (Диск и YouTube):** у каждого клиента свой Google. Владелец один раз проходит проверку Google для приложения content-studio, после этого клиент нажимает «Войти через Google» и даёт доступ к своему Диску. Создавать свой проект в Google Cloud клиенту не нужно. Для `drive.file` проверка простая, для `youtube.upload` нужна полная проверка Google (недели).
- **Claude:** клиент вводит свой ключ API Anthropic. Подписка владельца для чужого бизнеса не используется: условия подписки рассчитаны на личную работу.
- **Соцсети:** клиент входит в свои аккаунты сам, ключи хранятся у него.
- **Хранение:** база, ролики и ключи лежат у клиента (его ПК или его сервер). Владелец не видит чужих данных.
- **Что делать уже сейчас:** ни одного ключа, адреса или аккаунта в коде, всё через настройки. Конфиг rclone уже вынесен в `C:\src\rclone`.
